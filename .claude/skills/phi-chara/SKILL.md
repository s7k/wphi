# PHI のキャラグラを描く

Claude は画像を直接作れないので、次の順で描く。いきなり完成品を描かず、段階ごとに画像を見て確かめる。

1. 実物の写真を確かめ、誇張する特徴とポーズを言葉で決める(Step 0)
2. 素材(毛・顔・脚・岩の面・葉など)を記号で塗り分けた**配置図**を、`scripts/sprite_map.py` で描く
3. `scripts/material_shade.py` で陰影と輪郭を計算する
4. `scripts/pixel_sheet.py build` で BMP にし、8倍のプレビューを Read で見る
5. `scripts/pixel_sheet.py measure` で数値を確かめ、`scripts/lineup.py` で同梱の既存のキャラグラと並べて見る

色を1画素ずつ打つより、配置図と計算した陰影の方が、光の向きと輪郭が揃う。

## 1. 形式(コードで確かめた仕様)

`resources/phi/chara/<グラ名>.bmp`。96x160、24bit、teal(0,128,128) を透明にする(`src-tauri/src/assets.rs` の TEAL)。

| 領域 | 位置 | 大きさ | 使われ方 |
|---|---|---|---|
| 列0・1 | x=0, 16 | 16x32 | 通常の表示。`animFrame` の 0/1 で交互に出す |
| 列2・3 | x=32, 64 | 32x32 | 巨大キャラ(`gigant` が `*`)と、地図を 200% にした時(通常キャラも、`charaSrcRect` の `large`)。2枚を交互に出す |
| 行0〜3 | y=0, 32, 64, 96 | | 向き B・R・F・L(後ろ・右・正面・左)。`ui/src/mapRender.ts` の `dirToRow` |
| 下の 32 行 | y=128〜159 | | 地図では使わない。人物は顔のグラフィックと署名を置く例がある |

- 描く位置: マスの中で左右は中央、上下は床から 11px 持ち上げる(`CHARA_Y_ABOVE_FLOOR`)。足元をセルの下端に置けばよい
- 列2・3は「同じキャラの大きい版」。人物の d_fallen は翼や剣の動きを入れているが、猫・鶏は同じ姿の大きい版(猫は口を開けて鳴く絵)。動作を変えるかは描くキャラに合わせる
- 左向き(行3)は右向き(行1)の左右反転でよい
- 透過色に向けてぼかさない。teal に近い色(青緑)は使わない。不透明の teal があると `tools/png2phibmp` が止まる

## 2. ライセンスと置き場所

- 描き起こした絵は MIT で出す。新しい接頭辞の画像を足した時は `resources/phi/README.md` の表に1行足し、PCGL の対象外である事を書く(`alnes_*`、`sushi_*` と同じ扱い)
- PCGL の画像(`chara/` のそれ以外)を加工した物は PCGL のまま出す(PCGL d項)。混ぜない
- 生成に使ったスクリプトはリポジトリに残さない(BMP だけをコミットする)。作業は作業用のフォルダで行う

## 3. 目標の見た目

2000年頃のペインタリー系のドット絵。1セル40〜160色と多色で、色の散らばりもある。**色数の少なさは良さの指標ではない**。

### 3.1 どの絵にも共通
- **輪郭は純黒 #000000 の 1px で、外周を閉じる**(同梱の動物・モンスターは外周の平均輝度 0〜2、切れ目 0)
- 輪郭は**素材の外側**に足す。素材の縁を塗る方式だと、2px の脚や 1px の茎が黒い線になって消える
- 光は左上から
- 4つの向きを描き分ける。行を写すだけで済ませない
- 勝手な土台(土の山、根元の球、ベンチ状の台)を付けない。地面との接し方は実物に合わせる(ニンジンの肩の回りの土くらいは良い)

### 3.2 人物(手描きの d_fallen と、描き直す前の AI 生成の差。16x32)

| 指標 | d_fallen | AI 生成 | 目標 |
|---|---|---|---|
| 枠を埋める割合 | 76〜83%、上端 y=0 から | 35〜56% | 75%以上 |
| 外周の平均輝度 | 約6 | 40〜74 | 20以下 |
| 内側の一番暗い所(下位5%) | 約27 | 37〜61 | 30以下 |
| 一番鮮やかな色の彩度(上位5%) | 0.98 | 0.25〜0.81 | 0.9以上を1系統 |
| デフォルメ | 頭が大きく 2.5〜3頭身、髪と剣の光を誇張 | 実物をそのまま縮めた | 特徴を2つ誇張 |

### 3.3 動物・モンスター
- **飾りを付けない**(首輪・鈴など)。同梱の動物はどれも素の姿。鮮やかな色は、猫の毛色・鶏のとさか・金色の目のような自然な色で出す
- **白い動物に深い影を入れない**。白猫は明るさ 115〜237 の灰色の濃淡だけで、白さは黒い輪郭との対比で出している
- 頭を大きく、目は 1px の色

### 3.4 動き:棒立ちにしない
同梱の馬・猫・竜は、体のひねり・踏み出し・振り向きを必ず入れている。左右対称で脚が全部まっすぐの絵は、並べると浮く。
- **ひねり**: 横向きでも、胴を奥の塊(腰)と手前の塊(胸)に分け、手前を大きく低く、奥を小さく高くする。塊ごとに記号を分けて陰影を別に付ける。正面と後ろ姿も、片側の脇腹や肩を見せて斜めにする
- **頭**: 首を前に出し、傾けるか振り向かせる。羊なら長い鼻先を前下に向けた横顔が一番羊に見える
- **脚は骨格の通りに**: 前脚は肩から下へまっすぐで膝で少し曲がる。後ろ脚は膝から飛節が**後ろへ「く」の字**に折れ、そこから下はほぼ垂直。四つ足は歩く時、体重の約6割を前脚に掛ける
- **2コマの歩き**: A は手前の前脚を前に、手前の後ろ脚を後ろに伸ばした大股。B は脚が体の下ですれ違い、体が 1px 上がる
- **奥行き**: 奥の脚は1段暗くする

### 3.5 物・植物で効いた事
- **岩**: 上・左・右の3つの面で明るさを分ける(上を明るく、右を影)。面の中の陰影は小さく(`gradient` 0.15)、面どうしの差を大きく(`bias` ±0.42)。割れ目は「黒い溝」「左上の縁を少し明るく」「右下へ影」の3段で描き、主な割れ目は深く広く
- **鉱石**: 刃のような小さな結晶の面の集まり。面ごとに向きを変えて明るさを決め、光るのは光を向いた面の縁だけ。光沢は控えめにする(明るくすると浮く)。PHI の世界に合わせて灰色の濃淡にした
- **苔**: 上の面に大きく、縁を越えて側面へ垂れるように。面に合わせて苔の明るさも変える
- **葉**: 先の尖った葉を1点から放射状に。奥の葉を暗く、重なりの縁に暗い境目(`sep`)を入れて1枚ずつ見せる。葉脈は明るい1本
- **花**: 意図的に大きくし、花びらを1枚ずつ見せる(隣の花びらは明るさを交互に)。16x32 では数を減らして大きくする
- **細い茎**: 1px の茎は黒い輪郭で囲まれて重く見える。間を空けて本数を絞り、根元でだけ束ねる(ニンジン、麦)
- **形の読み違い**: 岩に刺さった剣が瓶に、巣箱の支柱が脚に、頭の毛が帽子に見えないか。シルエットを黒1色にして確かめる

### 3.6 大きさ(16x32 の横向き。輪郭を含む)

| 実物の大きさ | 例 | 16x32 | 32x32 |
|---|---|---|---|
| 小(〜40cm) | 猫、鶏、作物、草 | 14x16 くらい(正面は 9〜10x19) | 猫 26x22 |
| 中(50〜100cm) | 羊、岩、巣箱 | 16x18〜20 | 30x26 くらい |
| 人と同じかそれ以上 | 人物、馬、竜、木、掲示板 | 16x32 いっぱい(大きな四つ足は 3/4 の向きで縦に収める) | 31〜32x32 |

実物の大きさの順番を保ったまま縮める。並べた時の違和感は、ほとんどこの順番の崩れから来る。
32x32 はどれも枠いっぱいに描くので、16x32 ほどは大小の差が出ない。

## 4. 手順

### Step 0: 描く前に決めて、利用者に見せる
- 種別(人物・動物・物)と、各セルに何を描くか(第1章の表)
- **実物の写真を確かめる**(画像検索。利用者が写真をくれたらそれを優先)。その物らしさ(形、色、重さの掛かり方、表面)を言葉で書き出す
- **誇張する特徴を2つまで**(羊=丸い毛の胴と黒い長い顔、巣箱=わらの巻き目と出入口、ヤシ=垂れる櫛形の葉と実の房)。他は捨てる
- ポーズ(3.4)と大きさ(3.6)

### Step 1: 素材と色
- 素材ごとに 5〜8 段の色の並び(暗→明)。目や芯などは1色
- 人物は 3.2、動物は 3.3 の基準に合わせる

### Step 2: 配置図を描く
- `scripts/sprite_map.py` の `SpriteMap` で描く。座標は 32 マスの設計座標で書き、16x32 は `SpriteMap(16, 0.5, ky)` で同じ設計を縮める(ky は 0.6〜1.0、物の高さで決める)
- 楕円 `ell`、多角形 `poly`、関節つきの脚 `limb`、葉 `leaf`(`comb=True` でヤシの葉)、重なりの境目つきの塊 `blob`、1px の線 `line`
- 描く順番: 奥 → 手前(奥の脚 → 手前の脚 → 胴 → 首 → 頭 → 耳・毛 → 目・口)。後から描いた物が上に乗る
- 立体として別に陰影を付けたい塊は別の記号にする
- 左右と下の 1px は輪郭の為に空く(`SpriteMap` が守る)

### Step 3: 陰影と輪郭 → BMP → 目で見る
```sh
S=.claude/skills/phi-chara/scripts
python3 gen.py                                  # 配置図を書いた生成スクリプト(作業フォルダに置く)。mat.json を出す
python3 $S/material_shade.py mat.json spec.json
python3 $S/pixel_sheet.py build spec.json out.bmp   # out.bmp と out_preview.png(8倍)を作り、measure も走る
```
- `out_preview.png` を Read で見て、配置図を直す。脚や茎は 10〜14 倍に拡大して確かめる
- 生成スクリプトから `sprite_map` を読むには `sys.path.insert(0, ".claude/skills/phi-chara/scripts")` とする

### Step 4: 並べて確かめる
```sh
python3 $S/lineup.py line.png resources/phi/chara d_fallen:2 t_bhorse:1 t_catw:1 alnes_sheep:1 ./out.bmp:2
python3 $S/lineup.py line32.png --large resources/phi/chara d_fallen:2 t_bhorse:1 t_catw:1 ./out.bmp:2
```
- 基準にする同梱のキャラグラ: 人物 `d_fallen`・`t_darkknight`・`t_dragonknight`、動物 `t_catw`・`t_catrmt`・`t_bhorse`・`t_cockatrice`、モンスター `t_dragong`・`t_chimera`・`t_demon`、描き直した物 `alnes_*`
- 16x32 と 32x32 の両方を並べる

### Step 5: 見直す
- [ ] `measure`(人物は `character`、動物と物は `animal`)で ISSUES が出ない。物の静止したコマが同じなのは良い(同梱の馬も同じ)
- [ ] 並べた時に、大きさの順番・輪郭の黒さ・明暗の幅が揃っている
- [ ] 等倍でも何か一目で分かり、別の物に見えない
- [ ] 向きとコマごとに意味のある差がある
- [ ] 棒立ちになっていない

### Step 6: 渡す・入れる
- 利用者が BMP を落とせない時は zip にして渡す(チャットでは BMP が JPEG に変わる事がある)
- リポジトリには BMP と `resources/phi/README.md` の表の行だけを入れる

## 5. 既存のキャラグラを見直す時
- BMP のまま受け取る(JPEG では色も輪郭も測れない)。チャットで変わる時は zip で受け取る
- `measure` の数字を第3章の基準と比べる
- 同梱のキャラグラと横一列に並べ、「輪郭が弱い」「明暗の幅が狭い」「大きさの順番の崩れ」「棒立ち」「別の物に見える」「セルの使い方の取り違え」を探す

## 6. ツール(`scripts/`)

| ファイル | 内容 |
|---|---|
| `sprite_map.py` | 配置図を描くヘルパー(`SpriteMap`) |
| `material_shade.py` | 配置図 → 陰影と純黒の輪郭 → spec.json。素材ごとに `ramp`(色の並び)・`color`(1色)・`thin`(細い部位。左を明るく右を暗く)・`bias`(明るさのずらし)・`gradient`/`rim`(立体の強さ。平らな面は小さく)・`texture`(`fleece`・`fur`・`rock`)・`group`(同じ塊として陰影を付ける記号)。`mirror` で左右反転のセルを作る |
| `pixel_sheet.py` | `build`(spec.json → BMP と 8倍のプレビュー)、`measure`(セルごとの数値と ISSUES)、`compare`(2枚を横に並べる) |
| `lineup.py` | 複数のキャラグラの同じ向きを横一列に並べる |

mat.json の形:
```json
{
  "outline": "000000",
  "light": [-0.6, -0.8],
  "materials": {
    "W": {"ramp": ["5a544c", "7a7268", "9a9184", "b7ae9f", "cec6b7", "e0d9cb", "eee9de", "f8f5ee"], "texture": "fleece", "underside": true},
    "F": {"ramp": ["231d1f", "342b2e", "463c3f", "5c5155", "73686b"], "group": "f"},
    "E": {"color": "f2b40a", "group": "f"},
    "L": {"ramp": ["1e191b", "3a3235", "5a5054", "746a6e"], "thin": true},
    "l": {"ramp": ["1e191b", "3a3235", "5a5054", "746a6e"], "thin": true, "bias": -0.35},
    "A": {"ramp": ["2c2622", "433a34", "5c524a", "776b61", "938679", "afa294", "c9bdae"], "bias": 0.42, "gradient": 0.15, "rim": 0.6, "texture": "rock"}
  },
  "cells": {"0,1": ["16文字 x 32行"], "2,1": ["32文字 x 32行"]},
  "mirror": {"0,3": "0,1", "2,3": "2,1"}
}
```
セルの鍵は `"列,行"`。`.` は透明。build の前に spec.json へ `"kind": "animal"` を足すと、measure を動物と物の基準で行う。
